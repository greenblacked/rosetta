# Commit Message Template

```
<type>(<scope>): <summary, imperative, ≤72 chars>

<body: why, not what; wrap at 72 chars>

<footer: refs, e.g. "Refs: FR-AREA-001", "Closes #123">
```

Replace `<type>` with the repo's own detected prefixes (`feat`/`fix`/`chore`/`docs`/`refactor`, or the repo's own vocabulary). Omit footer refs the repo does not use. One logical change per commit.
